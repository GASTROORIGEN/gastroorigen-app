# GASTROORIGEN — Paso 1

Base inicial del MVP móvil para Android y iOS.

## Incluye
- Proyecto Flutter base.
- Pantalla principal de GASTROORIGEN.
- CTA de escaneo.
- Opción de subir fotografía.
- Accesos a Explorar, Historias y Mi GASTROORIGEN.
- Área reservada para el logo oficial, sin reinterpretarlo.

## Para ejecutar localmente
1. Instalar Flutter estable.
2. Abrir esta carpeta en VS Code o Android Studio.
3. Desde la raíz ejecutar `flutter create .` para generar las carpetas nativas de Android/iOS si aún no existen.
4. Ejecutar `flutter pub get`.
5. Ejecutar `flutter run` con un simulador o teléfono conectado.
