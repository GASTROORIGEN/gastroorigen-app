# Política de Privacidad — GASTROORIGEN

Estado: BORRADOR DE TRABAJO — NO PUBLICAR COMO TEXTO LEGAL FINAL TODAVÍA

Fecha de última actualización: pendiente

GASTROORIGEN utiliza funciones de cámara y selección de fotografías para identificar ingredientes y platillos y ofrecer información gastronómica relacionada.

## Información que puede procesarse

La aplicación puede procesar fotografías que el usuario toma o selecciona voluntariamente desde su dispositivo. Estas imágenes se envían de forma segura al servidor de GASTROORIGEN para realizar el análisis solicitado.

La aplicación también puede procesar información técnica necesaria para prestar el servicio, como datos de conexión, errores y métricas técnicas de funcionamiento, dependiendo de la configuración final de producción.

## Finalidad

Las imágenes se utilizan para identificar ingredientes o platillos y generar la ficha gastronómica solicitada por el usuario.

## Cámara y fotografías

GASTROORIGEN solicitará acceso a la cámara o a fotografías únicamente cuando el usuario decida utilizar esas funciones. La app no debe solicitar permisos que no sean necesarios para su funcionamiento.

## Compartición de información
